# Axios API Testing Example

## Project Description
This project automates API testing using `axios`, `chai`, and `mocha`.

## 📌 Installation
Run the following command to install dependencies:
```sh
npm install
```
## 🛠 Configuration
### Setting up the environment variables
This project uses a .env file to manage configuration settings like the base API URL. Create a .env file in the project root and add:
```sh
BASE_URL=http://localhost:3000

```

## 🚀 Run localhost

## 📝 Running Tests
```sh
npm test
```
